# Word Representations and Word-Sense Clustering

**Course:** CIS 5300 / HW4  
**Artifact type:** Course project / coursework

## Overview

Implemented count-based representations with TF-IDF and PPMI and compared them with pretrained dense embeddings. Explored semantic similarity, analogies, gender associations, and word-sense clustering.

## Guiding question

How do sparse and dense representations capture semantic relationships and distinguish word senses?

## Methods and technical scope

Python; TF-IDF; PPMI; embeddings; clustering.

## Evaluation and analysis

Evaluate similarity and clustering and inspect representational limitations. Association probes do not establish the absence or presence of all forms of model bias.
